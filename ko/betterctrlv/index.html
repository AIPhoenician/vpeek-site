복사한 내용을 기억합니다. Ctrl+V를 길게 눌러 이전 복사본을 선택하세요. ForumCore 제품입니다.

Windows용 클립보드 기록입니다. 평소처럼 붙여넣으려면 Ctrl+V를 탭하고, 이전 복사본을 고르려면 길게 누르세요. 기록은 PC에 남으며 Windows 계정용으로 암호화됩니다. Microsoft Store에서 구매하세요.

1–9  S↑  D↓  K‎ 삭제  L‎ 길게 눌러 지우기

  1. 복사와 잘라내기는 평소처럼 작동합니다. 잘라내면 원래 위치에서 항목이 제거됩니다.
  2. Ctrl+V를 짧게 누르면 평소처럼 가장 최근 복사본이 붙여넣어집니다. Ctrl+V를 누른 채 현재 클립보드(V)와 최근 아홉 개 중에서 선택하세요. 최신 항목이 맨 위에 표시됩니다.
  3. 1–9, S와 D, 올리거나 클릭하여 행을 선택하세요. K로 한 줄을 삭제합니다. L을 길게 누르면 지워집니다. Ctrl에서 손을 떼면 있던 창에 붙여넣습니다.

기록은 내 PC에 머물며 내 Windows 계정용으로 암호화됩니다. 암호 관리자에서 복사한 내용은 저장되지 않습니다. Microsoft Store에서 구매하세요.
