1–9  S↑  D↓  K‎ hapus  L‎ tahan: hapus

  1. Menyalin dan memotong tetap berjalan seperti biasa. Memotong akan menghapus aslinya.
  2. Ketuk Ctrl+V untuk menempelkan salinan terbaru, seperti biasa. Tahan Ctrl+V untuk memilih dari papan klip saat ini (V) dan sembilan salinan terakhir. Salinan terbaru di paling atas.
  3. 1–9, S dan D, arahkan atau klik untuk memilih baris. K menghapus satu baris. Tahan L untuk menghapus. Lepaskan Ctrl untuk menempelkan ke jendela tempat Anda berada.

Riwayat tetap di PC Anda, dienkripsi untuk akun Windows Anda. Salinan dari pengelola kata sandi tidak disimpan. Beli di Microsoft Store.
