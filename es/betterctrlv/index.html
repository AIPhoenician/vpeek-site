1–9  S↑  D↓  K‎ quitar  L‎ mantener: borrar

  1. Copia o corta como siempre. Al cortar, se elimina el original. Copiar y cortar siguen siendo de Windows.
  2. Pulsa Ctrl+V para pegar la copia más reciente, como de costumbre. Mantén pulsado Ctrl+V para elegir entre V (ahora) y tus últimas nueve copias. El más reciente aparece primero.
  3. 1–9, S y D, pasa el cursor o haz clic para elegir una fila. K elimina una fila. Mantén pulsada L para borrar. Suelta Ctrl para pegar en la ventana en la que estabas.

El historial se queda en este PC, cifrado para tu usuario de Windows. Se omiten las copias de administradores de contraseñas. La compra se hace en Microsoft Store.
