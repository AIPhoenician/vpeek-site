1–9  S↑  D↓  K‎ quitar  L‎ mantener: borrar

  1. Copiar y cortar siguen funcionando como siempre. Al cortar, se elimina el original.
  2. Pulsa Ctrl+V para pegar la copia más reciente, como de costumbre. Mantén pulsado Ctrl+V para elegir entre el Portapapeles actual (V) y tus últimas nueve copias. El más reciente aparece primero.
  3. 1–9, S y D, pasa el cursor o haz clic para elegir una fila. K elimina una fila. Mantén pulsada L para borrar. Suelta Ctrl para pegar en la ventana en la que estabas.

El historial se queda en tu PC, cifrado para tu cuenta de Windows. No se guardan las copias de administradores de contraseñas. Pruébalo 15 días y luego cómpralo en Microsoft Store.
