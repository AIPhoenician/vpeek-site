1–9  S↑  D↓  K‎ remover  L‎ segure para limpar

  1. Copie ou recorte como sempre. Ao recortar, o original é removido. Copiar e recortar continuam com o Windows.
  2. Toque em Ctrl+V para colar a cópia mais recente, como de costume. Segure Ctrl+V para escolher entre V (agora) e suas últimas nove cópias. O mais recente aparece primeiro.
  3. 1–9, S e D, passe o mouse ou clique para escolher uma linha. K remove uma linha. Segure L para limpar. Solte Ctrl para colar na janela em que você estava.

O histórico fica neste PC, criptografado para o seu usuário do Windows. Cópias de gerenciadores de senha são ignoradas. A compra é pela Microsoft Store.
